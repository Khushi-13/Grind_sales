📊 Pricing Analysis: End-to-End Data Analytics Project
A 3-Year Analysis of Gross Margin & Pricing Strategy (2023–2025)
📌 Project Overview

This project focuses on analyzing product profitability and identifying pricing inefficiencies across a 3-year sales dataset (2023–2025). The objective was to evaluate the impact of rising Cost of Goods Sold (COGS) on profit margins and provide actionable pricing recommendations to improve business performance.

🎯 Purpose

The business observed a significant decline in overall profit margins due to increasing COGS, tariffs, and operational costs.

Key Goals:
Identify low-performing products with Gross Margin Percentage (GMP) below 30%
Analyze Year-over-Year profitability trends
Provide data-driven pricing recommendations
Support strategic decisions like price adjustments or product discontinuation


🧰 Tech Stack
SQL – Data extraction, transformation, and aggregation
Power BI – Dashboard creation and data visualization
Excel – Data validation and exploratory analysis
Python (optional) – Data preprocessing and automation


📂 Data Source
Internal sales dataset (2023–2025)
Multiple relational tables including:
Orders
Customers
Products
Cost (COGS) data

Data was combined into a unified dataset by linking orders with product and customer information.

⚙️ Project Workflow
1. 🔹 Data Extraction
Built SQL queries to extract data from multiple tables
Combined 3 years of data into a single dataset
2. 🔹 Data Cleaning & Preparation
Cleaned missing and inconsistent values
Standardized formats for accurate analysis
Created a unified analytical dataset
3. 🔹 Data Analysis
Calculated Gross Margin Percentage (GMP) for each product

GMP = (Revenue - COGS) / Revenue​

Identified products with declining profitability

4. 🔹 Visualization

Built an interactive Power BI dashboard featuring:

Year-over-Year GMP trends
Revenue by Category
Product-level profitability
Regional performance

📊 Key Features
🔍 Identification of low-margin products (GMP < 30%)
📈 Year-over-Year profitability tracking
🌍 Region and category-level performance insights
📉 Detection of structurally unprofitable products
📊 Interactive dashboard for business decision-making

Key Insights
Rising COGS significantly reduced profit margins across multiple products
Several products became structurally unprofitable
Accessories and merchandise categories showed the lowest margins

💡 Pricing Recommendations
🚨 Immediate Action Required
Discontinue or increase price (≥25%) for:
Chemex Filters (100 pack) – 14.58% GMP
Minimalist Keychain – 15.59% GMP
Logo Hoodie (Black) – 16.34% GMP
Price Adjustment Needed
Increase price of Gooseneck Electric Kettle to restore GMP above 30%

👉 These actions are critical to counter rising costs and improve overall profitability.

📌 Business Impact
Enabled data-driven pricing decisions
Highlighted high-risk, low-margin products
Provided a roadmap for profitability optimization
Improved visibility into cost vs revenue dynamics
